# Code of Conduct

## Our pledge

We want JobTrace to be a welcoming, harassment-free project for everyone, regardless of age, background, disability, ethnicity, gender identity, experience level, nationality, appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

- Be respectful and constructive, especially when you disagree.
- Give and accept feedback graciously.
- Focus on what is best for the project and its users.
- Assume good intent, and ask when something is unclear.

## Unacceptable behaviour

- Harassment, insults, personal attacks or discriminatory language.
- Sexualized language or unwelcome attention.
- Publishing someone else's private information without permission.
- Trolling, sustained disruption of discussions, or spam.
- Any other conduct that would reasonably be considered inappropriate in a professional setting.

## Enforcement

Maintainers may edit or remove comments, commits, issues and pull requests that violate this code, and may temporarily or permanently ban contributors for behaviour they judge harmful.

To report a problem, open a private report through the repository's **Security** tab (private vulnerability reporting) and mark it as a Code of Conduct matter, or contact a maintainer through their GitHub profile. Reports are handled confidentially.

## Scope

This code applies in all project spaces (issues, pull requests, discussions) and when someone represents the project in public.
